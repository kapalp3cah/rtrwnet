Format CSV yang Diharapkan
Header baris pertama: no,username,password,profile,nas,service,ip,name,phone,address
  • no - Nomor urut (opsional)
  • username - Username (wajib, unique)
  • password - Password (opsional)
  • profile - Profile/Paket (opsional)
  • nas - NAS server (opsional)
  • service - Tipe service (opsional)
  • ip - IP Address (opsional)
  • name - Nama lengkap (default username)
  • phone - No telepon (opsional)
  • address - Alamat (opsional)
Contoh data: 
1,user001,pass123,20Mbps,router1,pppoe,192.168.1.100,John Doe,08123456789,"Jl. Merdeka No.1, Jakarta"
